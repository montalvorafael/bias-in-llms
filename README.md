# Thesis research files

Files for the thesis **Quantifying Bias and Stereotypes in Security-Related Text Using Large Language Models**.

## Folder structure

- `data/prompts/`: prompt dataset.
- `data/responses/`: combined and provider-specific model responses.
- `notebooks/`: original Colab notebook.
- `analysis/descriptive/`: descriptive statistics.
- `analysis/statistical/`: Friedman, Wilcoxon and post-hoc results.
- `analysis/checkpoints/`: intermediate datasets with metadata and scores.
- `analysis/lexical/`: lexical results.
- `analysis/sentiment/`: sentiment results.
- `analysis/ngrams/`: n-gram counts.
- `analysis/embedding/`: embedding inputs and results.
- `analysis/other/`: behavioral and disparity summaries.
- `figures/results/`: result images.
- `figures/pipeline/`: workflow image and editable-figure ZIP.
- `docs/`: supplied thesis PDF.

File contents and filenames are preserved from the supplied package. Only their locations were reorganized. The temporary Office lock file was omitted.
